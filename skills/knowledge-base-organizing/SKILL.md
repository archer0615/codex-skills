# Knowledge Base Organizing

## Use when

Use this skill when organizing scattered notes, documents, or links into a searchable and maintainable knowledge base.

## Inputs

- Required: Source notes, documents, links, intended users, and retrieval goals.
- Optional: Existing taxonomy, permissions, retention rules, authoritative sources, and migration constraints.
- Preconditions: Sources can be inventoried and provenance retained.
- Missing information: Preserve uncertainty, conflicts, and ownership gaps instead of silently merging sources.
- Output artifact: Information architecture, naming and tagging rules, migration order, ownership, and maintenance cadence.

## Procedure

1. Inventory sources and record their location, owner, audience, permissions, provenance, and update date where available.
2. Group material by user intent and lifecycle; identify duplicates, stale entries, gaps, and conflicting claims.
3. Determine authoritative sources with the user or from documented ownership. Preserve links and provenance for duplicates; do not delete or rewrite source material as part of classification.
4. Propose an information architecture, naming and tagging rules, and retrieval paths that fit the intended users.
5. Define a reversible migration order, ownership, maintenance cadence, and checks for links, permissions, freshness, and searchability.
6. Present unresolved source conflicts and decisions that require an owner; do not silently choose between them.

## Decision rules

- Prefer an authoritative source over duplicates, but preserve provenance and do not delete without confirmation.
- Organize for retrieval intent and lifecycle, not only existing folder structure.
- Keep facts, interpretations, drafts, and decisions distinguishable.
- Minimize sensitive data and preserve access boundaries, conflicts, and rollback options.

## Verification

- Sources, provenance, authority, lifecycle, and ownership are explicit.
- Duplicates, gaps, stale material, and unresolved conflicts are identified.
- Naming, tagging, retrieval, migration, and maintenance rules are actionable.
- The proposed structure supports the intended user intents.

## Output

Return the structured artifact, assumptions, unresolved questions, and concrete verification or review criteria. Communicate with the user in Traditional Chinese unless another language is requested.
